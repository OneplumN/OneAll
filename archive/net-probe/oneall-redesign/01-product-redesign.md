# OneAll 平台产品重构设计

## 1. 产品定位

OneAll 是一个面向运维团队的轻量控制台，核心价值是把资产、拨测、探针、告警、工单、通知串成闭环。

下一版不追求“大而全”，而是追求：

- 页面更清晰
- 链路更可解释
- 配置更集中
- 数据更可信
- 功能边界更干净

## 2. 一级模块

建议保留 5 个一级模块：

| 模块 | 说明 |
| --- | --- |
| 监控与告警 | 监控总览、告警事件、监控策略、探针节点、执行日志 |
| 资产中心 | 模型资产、模型管理、同步任务 |
| 一次性检验 | 域名拨测、证书检测、CMDB 域名校验 |
| 工单申请 | 申请、审批、执行、记录闭环 |
| 系统设置 | 平台参数、用户角色、凭据、数据源、通知、Webhook、审计 |

运维工具不作为业务重模块保留，统一放入独立“工具”分组，例如 IP 正则助手。

## 3. 全站信息架构

全站采用 5 个一级模块，二级页面先保持稳定，三级页面以详情、配置、历史记录为主。

```text
监控与告警
├─ 监控总览
├─ 告警事件
│  └─ 告警详情

│  ├─ 策略详情
│  └─ 规则配置
├─ 探针节点
│  └─ 探针详情
└─ 执行日志
   └─ 日志详情

资产中心
├─ 模型资产
│  └─ 实例详情
├─ 模型管理
│  ├─ 新建模型
│  ├─ 字段配置
│  └─ 权限与审计
├─ 同步任务
│  ├─ 同步预览
│  └─ 同步历史

一次性检验
├─ 域名拨测
├─ 证书检测
├─ CMDB 域名校验
└─ 检测记录

工单申请
├─ 新建申请
```

首版只保留独立“工具”分组，分组下提供 IP 正则助手。工具不放 Header，也不混入一次性检验。

## 4. 登录后默认页

登录后默认进入：

```text
/monitoring/overview
```

监控总览承担轻量工作台职责，展示：

- 活跃告警数
- 严重告警数
- 探针在线率
- 策略健康状态
- 最近告警事件
- 最近探针异常
- 快捷入口

## 5. 资产中心设计

资产中心按 CMDB 的模型驱动思想组织，但不克隆蓝鲸完整能力。首版采用“左侧模型树 → 模型实例列表 → 实例 Drawer”的工作台形态，保证用户看到的是具体模型的数据，而不是配置面板堆叠。

核心页面：

- 模型资产：左侧展示不分组模型树，默认选中域名模型；右侧只展示当前模型的实例数据，支持新增实例、查看、编辑、删除、搜索、筛选、分页、列显隐、列宽调整和排序；不展示摘要统计，不放新建模型、编辑字段、同步配置、导入、导出等模型配置入口
- 模型管理：只承载配置能力，不展示实例数据；包含新建模型、编辑模型、字段配置、字段禁用、唯一键、主显示字段和权限审计；允许删除模型，但删除前必须校验已有实例、同步任务、工单、告警和策略引用。字段排序不放在行内操作中，后续如需要再做独立排序模式。
- 同步任务：先选择目标模型和数据源，再配置“来源字段 → 目标字段”映射；禁用字段不参与映射，必填字段和唯一键必须映射；预览通过后才能执行写入，历史记录展示来源、模型、结果和时间

资产中心首版默认提供四个业务模型，按自定义模型一样维护；它们只是模型树里的模型项，不是全站二级导航，也不恢复“全部资产、域名资产、主机资产、应用资产”等固定资产菜单：

- CMDB 域名
- Zabbix 主机
- IPMP 项目
- 工单纳管主机信息

这些模型是资产数据页里的模型项，不是二级菜单；字段列按当前模型动态展示。

建议路由：

```text
/assets/models
/assets/model-management
/assets/model-management/new
/assets/model-management/:modelId/fields
/assets/model-management/:modelId/permissions-audit
/assets/sync-tasks
```

## 6. 数据源与凭据

蓝鲸 CMDB、Zabbix、LDAP、Grafana 都不再单独散落在不同模块中，而是统一进入：

```text
系统设置 / 数据源管理
```

敏感信息统一进入：

```text
系统设置 / 凭据管理
```

这样用户配置资产同步时，只需要：

1. 新建凭据
2. 新建数据源
3. 在模型管理中定义平台字段
4. 在同步任务中配置外部字段到平台字段的映射
5. 预览同步
6. 执行同步

## 7. 告警与工单闭环

核心链路：

```text
探针执行检测
→ 回传检测结果
→ 告警规则判断
→ 生成告警事件
→ 通知用户
→ 用户查看全链路
→ 创建工单
→ 工单处理
→ 告警关闭或恢复
```

告警详情必须展示：

- 关联资产
- 关联策略
- 执行探针
- 检测任务
- 最近检测结果
- 通知记录
- 工单记录
- 操作日志
