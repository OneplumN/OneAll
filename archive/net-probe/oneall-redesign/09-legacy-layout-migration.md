# 旧平台页面布局迁移规则

本文件约束当前 React + Ant Design 原型的页面改造边界：所有页面的页面布局、信息密度、筛选区、表格位置、分页、详情抽屉和弹窗形式复刻旧 OneAll 平台；技术实现不迁移 Vue / Element Plus。

视觉原则：旧平台决定信息架构和页面骨架，Ant Design 决定企业级视觉表达。表格统一使用 AntD 原生 `Table`，禁止通过覆盖 `.ant-table-*` 内部类去仿 Element Plus 或旧平台表格。

## 1. 全站页面骨架

所有一级和二级页面统一采用旧平台的 `RepositoryPageShell` 思路：

- 顶部只保留紧凑标题区：模块路径、页面标题、说明和右侧主操作。
- 主内容优先使用单一白色面板，不再使用大 Hero、营销式卡片或多层卡片嵌套。
- 列表页结构固定为：工具条 -> 可选摘要条 -> 表格 -> 底部分页。
- 详情页结构固定为：详情标题 -> 基础信息区 -> 证据/记录表格 -> 右侧时间线或动作区。
- 工具页结构固定为：左侧配置表单 -> 右侧结果面板 -> 历史记录表格。

## 2. 列表页规则

适用页面：告警事件、监控策略、探针节点、执行日志、模型资产、同步任务、工单队列、用户、权限、审计、通知。

- 工具条使用左操作、右筛选布局。
- 主操作按钮靠左，筛选、搜索靠右。
- 表格是页面主体，禁止用大卡片堆叠替代表格。
- 表格组件必须使用 AntD 原生 `Table`；允许配置 columns、rowSelection、scroll、pagination，不允许自定义 AntD 表头、单元格、斑马纹和 hover 的全局 CSS。
- 表格操作列固定在右侧，操作文本保持短：详情、编辑、执行、审批、关闭。
- 分页固定在底部，左侧显示总数和 page size，右侧显示翻页。

## 3. 详情页规则

适用页面：告警详情、策略详情、探针详情、执行日志详情、资产详情、工单详情。

- 详情页不做大面积视觉装饰。
- 左侧主面板展示业务事实：基础字段、检测证据、审批记录、关联对象。
- 右侧窄栏展示状态流、推荐动作、健康摘要或审计时间线。
- 所有详情操作必须来自当前业务状态和权限，不写死无效按钮。

## 4. 表单页规则

适用页面：拨测监控申请、新建模型、字段配置、同步配置、平台参数、认证接入。

- 表单按旧平台分区：基础信息、业务配置、高级配置、提交结果。
- 主要提交按钮放在标题区或表单底部，避免多个主按钮抢占视线。
- 表单校验错误在字段附近展示，不使用浮夸提示卡。

## 5. 当前落地顺序

1. 资产中心：采用左侧不分组模型树、右侧实例表格、实例 Drawer；删除摘要统计、模型关系、业务拓扑、模板卡片和模型资产页配置入口。
2. 监控与告警：告警事件、监控策略、执行日志统一列表布局。
3. 工单申请：队列页和申请页按旧平台拨测申请结构收敛。
4. 系统设置：用户、权限、数据源、凭据、通知、审计统一列表和表单布局。
5. 一次性检验：域名拨测、证书检测、CMDB 校验按旧平台工具页结构收敛。
