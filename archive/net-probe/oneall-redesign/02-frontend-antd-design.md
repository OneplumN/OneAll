## 2. 页面结构

统一布局：

```text
Layout
├── Sider：一级导航
├── Header：通知、用户头像
└── Content：页面内容
```

统一页面结构：

```text
Page
├── PageHeader：标题、说明、主按钮
├── Toolbar：搜索、筛选、批量操作
├── Content：表格、详情、看板、表单
└── Drawer / Modal：复杂配置和确认操作
```

## 3. Ant Design 组件约定

| 场景 | 组件 |
| --- | --- |
| 页面布局 | `Layout`, `Sider`, `Header`, `Content` |
| 数据表格 | `Table` |
| 搜索筛选 | `Input`, `Select`, `DatePicker` |
| 状态展示 | `Tag`, `Badge`, `Progress` |
| 指标卡 | `Card`, `Statistic` |
| 复杂配置 | `Drawer` |
| 操作确认 | `Modal` |
| 流程步骤 | `Steps` |
| 分组切换 | `Tabs` |
| 用户反馈 | `message`, `notification` |

## 4. 资产中心页面

当前原型已包含：

- 模型资产主工作台
- 模型管理页
- 资产表格
- 同步变更预览

设计重点：

- 左侧导航保留“模型资产 / 模型管理 / 同步任务”
- 模型资产页参考 CMDB 工作台结构：内容区左侧是不分组模型树，右侧是当前模型实例表，默认选中域名模型
- 模型资产页只展示当前模型的具体实例数据，不放模板、说明卡、模型配置入口和统计概览
- 模型资产页允许实例级动作：新增实例、查看、编辑、删除；支持搜索、筛选、分页、列显隐、列宽调整和排序
- 模型管理承载模型结构配置：新建模型、编辑模型、字段配置、唯一键、主显示字段和权限审计；不进入实例列表页
- 表格列动态但展示稳定
- 同步前必须可预览
- 同步后必须可追溯
