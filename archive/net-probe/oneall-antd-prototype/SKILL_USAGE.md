# OneAll AntD Prototype · Skills 调用说明

本目录是独立前端设计原型，不连接后端，不复用旧 OneAll 前端页面。

## 使用的 skills

### jeecg-onlform

用于资产中心的模型字段管理、字段控件类型、字段映射、动态表格与同步表单。

落地到代码：

- `资产中心` 左侧模型列表
- `字段配置 Drawer`
- 字段项：字段名、显示名、字段类型、来源字段映射
- 动态资产表格：按模型字段展示资产数据

### jimubi-dashboard

用于监控总览的看板结构。该 skill 的仪表盘思想是 24 栅格、统计卡片、表格/图表组合。

落地到代码：

- `监控总览` 顶部 4 个指标卡
- 最近告警表格
- 全链路摘要卡片
- Ant Design `Statistic` + `Card` 的看板式布局

### jeecg-bpmn

用于工单申请的审批流程设计。这里不创建真实 Flowable/BPMN，只把审批链路表达成前端信息架构。

落地到代码：

- `工单申请` 的全部/我的/待审批 Tab
- 工单状态标签：待审批、执行中、已完成
- 后续可继续扩展审批详情、审批记录、执行记录、操作日志

### frontend-design

用于最终前端 UI 生成与视觉约束。

落地到代码：

- React + Ant Design
- 无后端 mock 原型
- 干净的运维控制台风格
- 不做营销页、不做复杂拓扑
